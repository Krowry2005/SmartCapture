🍎 iPhone / iPad (USB接続)

USB接続によるデバイス検出および画面ミラーリング(実験的)に対応しています。映像のみで、音声は未対応です。

iOSの仕様上、端末の「信頼」と、PC側でWinUSBドライバーの導入(Zadig等)が必要です。ドライバー導入後は iTunes から端末が見えなくなる場合があります。

端末を選択して「接続」を押すと開始します。ロック解除した状態でお試しください。

USBとWi-Fiの選び方 / Wi-Fi接続の手順

🔌 USB接続

  • 安定: 遅延・コマ落ちが少ない
  • 簡単: ケーブルを挿すだけ
  • 充電: 配信しながら充電できる
  • 注意: ケーブルの長さに縛られる

📶 Wi-Fi接続

  • 自由: ケーブル不要で端末を動かせる
  • 設定: 初回にペア設定が必要 (Android 11以降)
  • 回線: 電波状況で映像が乱れることがある
  • 条件: PCとスマホを同じネットワークに

配信・録画を優先するならUSB、手軽に離れて使いたいときはWi-Fiがおすすめです。

Wi-Fi接続の4ステップ

  1. PCとスマホを同じWi-Fiに接続します。
  2. スマホの「開発者向けオプション」で「ワイヤレスデバッグ」をONにします。
  3. 初回のみ、「ペアリングコードによるデバイスのペア設定」を開き、PCで adb pair IP:ポート を実行して表示されたコードを入力します。
  4. 上の「Wi-Fi接続」タブを選び、検出された端末を選んで「接続」を押します。見つからない場合は、手動入力欄に「ワイヤレスデバッグ」画面の IP:ポート を入力してください。

Android 10以下: 一度USB接続して adb tcpip 5555 を実行すると、Wi-Fiで接続できます。

Android の「ワイヤレスデバッグ」に表示された IP とポートを入力します。初回は事前のペア設定が必要です。
